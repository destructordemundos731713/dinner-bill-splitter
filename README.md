# 🍽️ Dinner Bill Splitter

A simple Python script that sums up restaurant expenses by category, calculates a 25% tip, and splits the final rounded total evenly among a group of friends.

## 🚀 Features
* Combines specific expense variables (appetizers, main courses, desserts, and drinks) into a running total.
* Automatically calculates a 25% tip.
* Splits the final bill among 4 friends and uses the `round()` function for practical payment splitting.

## 🛠️ Technologies Used
* Python 3
* Built-in arithmetic operators and mathematical formatting.
